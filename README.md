## Project Overview

The **Library Management System** is a DBMS Capstone Project developed using **MySQL and SQL**. The system is designed to organize and manage library information in a structured relational database.

The system manages information related to books, authors, publishers, categories, suppliers, members, librarians, issues, fines, and reservations.

---

## Project Objectives

- Identify the major entities and attributes of the library system.
- Establish relationships between the entities.
- Design the Entity–Relationship (ER) diagram.
- Convert the ER model into a relational database schema.
- Implement the database using SQL.
- Maintain data integrity using Primary Keys and Foreign Keys.
- Reduce data redundancy and maintain consistency.
- Provide efficient retrieval and management of library records.

---

## Database Entities

The system contains the following 10 entities:

1. AUTHOR
2. PUBLISHER
3. CATEGORY
4. SUPPLIER
5. BOOK
6. MEMBER
7. LIBRARIAN
8. ISSUE
9. FINE
10. RESERVATION

---

## Database Design

The database is normalized up to **Third Normal Form (3NF)** to reduce data redundancy, inconsistency, and update anomalies.

**Normalization:**  
`UNF → 1NF → 2NF → 3NF`

The project includes both **software-based and manual ER diagrams**.
